# Brainy AI — Day 1 Foundation

A vanilla HTML/CSS/JavaScript study dashboard foundation.

## Files
- `index.html` — page structure
- `style.css` — responsive premium UI and dark/light theme
- `app.js` — navigation, theme toggle, focus timer, local progress

## Run
Open `index.html` in a browser. No build step or framework required.

## Current scope
This is the first foundation build. AI chat, notes, and quiz features are placeholders and are not connected to an AI model yet. A real AI feature will require a secure backend/API integration; do not put secret API keys in frontend code.

Focus data is stored in this browser's localStorage.
